Objetivos del Sistema

El sistema pemitira al usuario:

  • Registrar ingresos y gastos.
  • Visualizar el estado de sus finanzas.
  • Obtener recomendaciones financieras.
  • Realizar seguimiento a sus hábitos de consumo.
4

Requisitos del Sistema

Para utilizar la aplicación, el usuario debe contar con:

  • Navegador web actualizado (Google Chrome, Firefox, Edge).
  • Conexión a internet.
  • Dispositivo (computador, tablet o celular).
5

Acceder al registro

Registro:

Desde la pantalla de inicio, el usuario debe seleccionar la opción “Regístrate” para comenzar el proceso de creación de cuenta.

6

Completar el formulario

Registro:

El usuario deberá ingresar sus datos personales, correo electrónico, número telefónico y crear una contraseña segura para continuar.

7

Aceptar términos y condiciones

Registro:

Antes de finalizar el registro, es necesario leer y aceptar los términos y condiciones de uso de la plataforma.

8

Confirmación de registro exitoso

Registro:

El sistema mostrará un mensaje de confirmación indicando que la cuenta fue creada correctamente.

9

Iniciar sesión

Acceso:

El usuario deberá ingresar el correo y contraseña registrados para acceder a su cuenta.

10

Verificación de seguridad

Acceso:

Como medida de protección, el sistema solicitará un código de verificación enviado al correo electrónico del usuario.

11

Explorar el panel principal

Panel principal:

Una vez dentro de la plataforma, el usuario podrá conocer las funciones principales, acceder a contenido educativo y navegar por las diferentes secciones disponibles.

12

Explorar el panel principal

Panel principal:

Continuación: el usuario puede explorar el resumen de ingresos, egresos, metas de ahorro y acceder a los módulos de gestión financiera.

13

Panel Inicio: resumen financiero

Panel Inicio:

El usuario podrá visualizar un resumen general de su actividad financiera, incluyendo balance total, ingresos, egresos y análisis gráfico del comportamiento económico del período seleccionado.

14

Historial y seguimiento financiero

Panel Inicio:

La plataforma permite consultar movimientos recientes, revisar el historial mensual y visualizar el cumplimiento de metas para un mejor control financiero.

15

Gestión de ingresos (detalle)

Ingresos:

En esta sección el usuario podrá administrar detalladamente los ingresos registrados, consultar información específica, exportar reportes y editar registros existentes.

16

Análisis de ingresos

Ingresos:

El sistema presenta herramientas gráficas que permiten analizar la evolución y distribución de las fuentes de ingresos registradas.

17

Gestión de egresos (detalle)

Egresos:

El usuario podrá consultar y gestionar los gastos registrados, visualizar el saldo disponible y realizar acciones de edición o exportación de información.

18

Análisis de egresos

Egresos:

La plataforma proporciona gráficos estadísticos que permiten analizar el comportamiento y distribución de los gastos según sus categorías.

19

Consultar módulo de Deudas

Deudas:

El usuario debe ingresar al módulo Deuda desde el menú principal para visualizar el resumen general de obligaciones financieras. Allí podrá revisar el saldo pendiente, pagos realizados, fechas de vencimiento y estadísticas relacionadas.

20

Detalles y estadísticas de deudas

Deudas:

La plataforma proporciona gráficos y estadísticas detalladas sobre las obligaciones financieras, permitiendo al usuario analizar la evolución de sus deudas y planificar los pagos pendientes.

21

Agregar nueva deuda

Deudas:

Presiona el botón Agregar para registrar una nueva deuda. El sistema abrirá un formulario donde deberás ingresar la entidad acreedora, tipo de deuda, saldo inicial, tasa, fecha de vencimiento y demás datos necesarios.

22

Registrar un nuevo pago

Deudas:

Selecciona la opción Agregar pago para registrar abonos realizados a una deuda existente. Debes indicar la deuda asociada, monto pagado, método de pago y observaciones adicionales.

23

Ingresar al módulo Ahorro

Ahorro:

Accede al módulo Ahorro desde el menú principal para visualizar las metas creadas. El sistema mostrará las metas disponibles, el porcentaje de avance y las opciones de administración.

24

Crear nueva meta

Ahorro:

Presiona Crear tu propia meta para configurar un nuevo objetivo de ahorro. Debes ingresar nombre de la meta, imagen, monto objetivo, tiempo estimado y frecuencia de aportes.

25

Realizar aportes a una meta

Ahorro:

Selecciona una meta y presiona Aportar. El sistema permitirá elegir una fecha y definir el monto que deseas agregar para avanzar hacia el cumplimiento del objetivo.

26

Consultar historial de aportes

Ahorro:

Haz clic en Ver historial para consultar el registro completo de aportes realizados. Desde este apartado podrás visualizar fechas, montos y estadísticas de progreso.

27

Opciones del menú de la meta

Ahorro:

Presiona el botón de tres puntos (...) ubicado en la tarjeta de la meta para desplegar las opciones disponibles, como editar o eliminar.

28

Editar meta

Ahorro:

Selecciona la opción Editar para modificar la información de una meta existente. Puedes actualizar nombre, imagen, duración, frecuencia o monto objetivo.

29

Eliminar meta

Ahorro:

Selecciona la opción Eliminar para borrar una meta. El sistema mostrará una advertencia y permitirá descargar el historial antes de confirmar la eliminación definitiva.

30

Meta completada

Ahorro:

Cuando el progreso alcance el 100%, el sistema mostrará el estado Meta completada, indicando que el objetivo fue alcanzado satisfactoriamente. Desde allí podrás revisar el historial y cerrar el proceso.

31

Botones superiores derechos

Accesos Rápidos:

Explica la función de los accesos rápidos: Manual de usuario, Chatbot, Usuario y Configuraciones, además del acceso al perfil y cierre de sesión.

32

Editar perfil

Perfil:

Permite actualizar datos personales como foto, nombre, correo, teléfono y contraseña.

33

Cambiar contraseña

Seguridad:

Guía para ingresar la contraseña actual, crear una nueva, confirmarla y guardar cambios.

34

Verificación de seguridad

Seguridad:

Solicita la contraseña actual para validar la identidad antes de realizar cambios importantes.

35

Acceder al chatbot

Asistencia:

Permite abrir el asistente virtual para recibir ayuda inmediata y consultar preguntas frecuentes dentro de la plataforma.

36

Interactuar con el chatbot

Asistencia:

Explica cómo escribir preguntas o solicitudes en el chat para recibir respuestas automáticas del asistente virtual.

37

Revisar notificaciones

Notificaciones:

Muestra cómo acceder al Centro de Notificaciones para visualizar alertas y mensajes importantes.

38

Personalizar notificaciones

Notificaciones:

Permite configurar el tiempo y las preferencias para silenciar o administrar notificaciones.

39

Iniciar sesión con Google

Acceso:

Muestra una segunda forma de acceso usando Google para iniciar sesión o registrarse de forma rápida y segura.
