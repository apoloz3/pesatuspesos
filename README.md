💰 Pesa Tus Pesos
“Haz que cada peso cuente”
Pesa Tus Pesos es una aplicación web educativa y tecnológica diseñada para ayudar a jóvenes y adultos a gestionar sus finanzas personales de manera sencilla, eficiente y didáctica.

📌 Descripción del Proyecto
Pesa Tus Pesos permite a los usuarios llevar un control detallado de sus ingresos y gastos, fomentando hábitos financieros saludables mediante el análisis de datos, consejos personalizados y herramientas de seguimiento en tiempo real.
Este proyecto está orientado a la comunidad educativa del SENA y busca mejorar la educación financiera a través de la tecnología.

🎯 Objetivos
Objetivo General
Desarrollar una aplicación web que facilite la gestión de finanzas personales y promueva una mejor toma de decisiones económicas.
Objetivos Específicos
Registrar ingresos y gastos de forma organizada
Generar reportes y visualizaciones financieras
Ofrecer consejos personalizados según el comportamiento del usuario
Fomentar hábitos de ahorro
Brindar una experiencia intuitiva y accesible
🚀 Funcionalidades
👤 Registro e inicio de sesión de usuarios
💵 Registro de ingresos y gastos
📊 Visualización de reportes financieros
📅 Historial de movimientos
🔔 Consejos financieros personalizados
📱 Diseño responsive (adaptable a móviles)
🔐 Seguridad en autenticación de usuarios

El proyecto se desarrolla bajo un enfoque cualitativo, analizando el comportamiento financiero de los usuarios mediante encuestas y uso de la plataforma para generar mejoras en hábitos económicos.
